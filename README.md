# Rejestry i VAT — редизайн экрана

Тестовое задание: адаптировать и улучшить экран «Rejestry i VAT» — проще, чище, удобнее, без потери полей и действий, с состояниями «данные / пусто / ошибка» и адаптивом от iPhone SE до десктопа.

## Готовое демо — `demo/`

Откройте **`demo/index.html`** в браузере (двойной щелчок; нужен интернет для шрифта и иконок).

На панели сверху:
- **Widok: Komputer / Telefon** — десктопная и мобильная версия (iPhone SE 375×667, iPhone 14 390×844);
- **Motyw: Jasny / Ciemny** — светлая и тёмная тема;
- **Ekran** — Główna, Rejestr VAT, заглушка остальных разделов;
- **Nowa karta** — открыть текущий экран отдельно.

| Экран | Описание |
|---|---|
| `demo/glowna.html` | Главная «Obszary księgowe». Компьютер — панель с навигацией, виджетом реестра VAT, задачами и доступностью разделов. Телефон (≤760 px) — поиск по разделам, документам и контрагентам. |
| `demo/rejestr.html` | «Rejestry i VAT»: список документов + карточка документа, период, фильтры (rok, miesiąc, rodzaj operacji, kod JPK V7, serie), итоги Netto/VAT/Brutto и по ставкам, сортировка, пагинация, экспорт, печать, метки, настройка полей. Переключатель состояний «Dane / Pusto / Błąd» внизу слева. |
| `demo/wkrotce.html` | Заглушка для разделов, которых нет в задании. |

Переход с главной в реестр и переключатель Sprzedaż / Zakupy анимированы; при системной настройке «уменьшить движение» анимации отключаются.

### Тест вёрстки

`demo/test/` — автоматическая проверка всех экранов на 16 ширинах (320–1920 px) в обеих темах: горизонтальный скролл, элементы и меню за пределами экрана, перекрытие открытых меню другими элементами, текст, выходящий из блоков, сдвиги при загрузке (CLS), состояния, меню, карточка документа на телефоне. Весь прогон (~1400 проверок) занимает несколько секунд.

```bash
cd demo
node serve.js
```

Затем откройте http://localhost:5174/test/ (прототип — http://localhost:5174/).

## Поиск направления — `designs/`

Этапы работы над дизайном (открываются через `node serve.js` в корне → http://localhost:5173/):

- `index.html` — галерея 7 концептов экрана реестра;
- `01…07-*.html` — концепты (выбран **03 «Podgląd»**);
- `03-podglad-kolory.html` — 6 цветовых вариантов выбранного концепта;
- `home-1…7-*.html` — 7 вариантов главной (для компьютера выбран **2 «Panel»**, для телефона — **3 «Wyszukiwarka»**);
- `mobile.html` — просмотр экранов в рамках телефонов.

Все данные демонстрационные.
