Rejestry i VAT — демо-прототип
================================

Как открыть
-----------
Откройте файл index.html двойным щелчком (Chrome, Edge, Safari или Firefox).
Нужен интернет: шрифт Onest и иконки подгружаются из CDN.

На верхней панели демо:
  • Widok: Komputer / Telefon — переключает между десктопной и мобильной версией
    (для телефона есть размеры iPhone SE 375×667 и iPhone 14 390×844);
  • Motyw: Jasny / Ciemny — светлая и тёмная тема;
  • Ekran: Główna / Rejestr VAT / Pozostałe — быстрый переход между экранами;
  • Nowa karta — открыть текущий экран отдельно, во весь браузер.

Экраны
------
  glowna.html   — главная «Obszary księgowe»: на компьютере — панель с навигацией и виджетами,
                  на телефоне (≤760 px) — поиск по разделам, документам и контрагентам;
  rejestr.html  — «Rejestry i VAT»: список документов и карточка документа, период, фильтры,
                  итоги и ставки VAT, сортировка, пагинация, экспорт, печать, метки;
                  внизу слева — переключатель состояний «Dane / Pusto / Błąd»;
  wkrotce.html  — заглушка для разделов, которых нет в задании.

Переход с главной в реестр анимирован (Chrome/Edge при открытии через http — плавное «перетекание»
заголовка; в остальных случаях — лёгкое появление страницы).

Тест вёрстки
------------
test/index.html — автоматическая проверка всех экранов на 16 ширинах (320–1920 px) в обеих темах:
горизонтальный скролл, элементы и меню за краем экрана, перекрытие открытых меню другими элементами,
текст, выходящий из блоков, состояния, пагинация, фильтры, карточка документа на телефоне.
Для него нужен локальный сервер (iframe-проверки не работают с file://). В папке демо:
    node serve.js
и затем http://localhost:5174/test/  (сам прототип — http://localhost:5174/)
